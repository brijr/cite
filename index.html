A script you drop on any website

Cite injects an isolated overlay. Click an element, write the change, and copy a bundle — selector, HTML, computed CSS, nearby DOM, and the request — ready to paste into Claude, Cursor, or Codex.

No accounts. No backend. No build step. Works on anything that renders a DOM.

<script src="https://cite.brijr.dev/cite.js"></script>

Use

  1. Press Alt+C to inspect, or click Inspect
  2. Tab or arrows to an element. Enter cites it
  3. Write the change. Cmd+Enter saves. Esc backs up
  4. Alt+Shift+C copies the bundle for the agent

Keys

  • Alt+C — inspect
  • Tab / Shift+Tab — next / previous element
  • Arrows — move
  • Enter — cite this element
  • Cmd+Enter — save request
  • Alt+Shift+C — copy for agent
  • Alt+P — annotations
  • ? — shortcut list
  • Esc — back

What gets copied

  • Selector — unique CSS path
  • Text — visible label
  • HTML — serialized element
  • CSS — type, color, radius, layout
  • Nearby — parent, previous, next
  • Box — size, viewport, scroll
  • URL — path and title
